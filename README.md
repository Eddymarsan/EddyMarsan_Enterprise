# EddyMarsan Enterprise System

A web-based business management system for selling electronics and providing computer repair services.

## Features
- User registration and login
- Product listing with images and stock management
- Session-based shopping cart
- Admin dashboard and statistics
- Computer repair requests and status tracking
- Responsive user interface

## Technologies
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Database: MySQL
- Local Development: XAMPP

## Installation
1. Clone or download this repository.
2. Move the project folder to `C:\xampp\htdocs\EddyMarsan`.
3. Start Apache and MySQL in XAMPP.
4. Import the database SQL file using phpMyAdmin.
5. Configure database credentials in `config.php`.
6. Open `http://localhost/EddyMarsan/` in your browser.

## Security
Use secure password hashing, prepared SQL statements, and role-based access control. Never upload database credentials or passwords to GitHub.
